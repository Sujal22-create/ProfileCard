# Week 1 Assignment: Profile Card with Light & Dark Theme

## Files
- `index.html`: page structure
- `style.css`: card layout and both themes
- `script.js`: `setLight()` and `setDark()` functions
- `light.jpg` and `dark.jpg`: starter profile illustrations (replace with your own photos if desired)
- `icons/`: the five supplied SVG icon files

## Run on Android
1. Extract this project ZIP.
2. Open `index.html` in a browser, or import the folder into your coding editor / hosting workspace.
3. Change `Your Name`, the bio, email address, and links in `index.html`.
4. Replace the starter portrait files if you want to use your own images.

The implementation follows the assignment's requested separate HTML/CSS/JS files, Flexbox centering, default dark theme, body `light-mode` class, theme-specific profile images, and `<img>` tags for icons.
